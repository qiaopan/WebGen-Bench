官方协议只生成一次、不修复。第一阶段我们自己的补丁把这类错误掩盖了；按官方协议跑，这些错误就暴露出来，而且 No Memory 同样会犯。

第三个挑战：真正致命的失败发生在代码层。旧版 Long Memory 74 题里有 26 题白屏，其中 19 题是 import 了 vue-router 却没在 package.json 里声明。而生成器的 81 次回复里，一次都没有改过 package.json。第一阶段我们自己的修复补丁把这类错误掩盖了；按官方协议一次生成、不修复，它们就全部暴露出来，No Memory 也一样会犯。所以结论是：记忆必须作用在代码层，而且必须是生成器写自己的文件就能做到的事。
