角色设置
生成器WebGen-LM-7B（vLLM），Bolt.diy，只生成一次、不修复
功能 / 外观评测Qwen2.5-VL-32B（论文外观用 GPT-4o，这是唯一偏差）

指标准确率 =（通过 + 0.5×部分通过）/ 检查数；外观 1–5；零分题数
基线复现No Memory 101 题 28.5%（论文 28.4%，Lu et al., 2025）
实验设置。全部模型都部署在学校集群上，不调用任何商业 API。生成器是 WebGen-LM-7B，用 Bolt.diy，只生成一次、不修复。功能和外观评测都用 Qwen2.5-VL-32B；论文的外观评测用 GPT-4o，这是唯一的偏差，所以外观分只在我们自己的组之间比较。记忆和反思用 72B 模型。单个任务大约 12 分钟。准确率等于通过数加一半的部分通过数，除以检查数。No Memory 复现出 28.5%，和论文的 28.4% 几乎一样，说明评测管线是可信的。
