版本迭代

每一版都由上一版的错误分析驱动

版本做了什么暴露的问题
旧版文字经验 + 通用池白屏多；空泛条目反复注入
v4+ 需求清单、去重、效用排序前 30 题好，后期输给 No Memory
v6+ 代码池、具体化过滤、退役一行 import 示例 → 交脚手架（3/13）
v7+ 示例须含调用行、去文件包装；统计块不注入剩余：少量缺 import（7B 基础错误）

迭代流程：本地小样本（3–5 题）只做代码检查 → 有效才上集群，集群一次只跑一个冻结版本。

这一页把版本串起来。旧版是文字经验加通用池，白屏多、空话反复注入；v4 加了需求清单、去重和效用排序，前期好、后期输给 No Memory；v6 加了代码池、具体化过滤和退役机制，但一行 import 的示例导致交回模板；v7 要求示例带调用行、去掉文件包装，统计块也不再注入。我们的流程是：新想法先在本地 3 到 5 题上只做代码检查，有效才上集群，集群一次只跑一个冻结的版本。v5 只是本地调试版。
