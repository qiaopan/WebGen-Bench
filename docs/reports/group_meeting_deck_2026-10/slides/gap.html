去掉难度：同一题上与 No Memory 的差

每个点 = 最近 10 题（v7 − No Memory）或（v4 − No Memory）的平均差，单位百分点；正值表示 Long Memory 更好。

这一页去掉难度：每个点是最近 10 题里，同一道题上 Long Memory 减去 No Memory 的平均差。正值表示带记忆更好。前 30 题两个版本都领先。到第 40 到 60 题，v4 一路往下，最低落后 No Memory 大约 27 个百分点；v7 基本在零线附近或以上。第 60 题以后，v7 稳定领先 10 到 25 个百分点，v4 在零附近波动。所以后段准确率变低是题目难，而 v7 相对基线的优势一直保持着。
