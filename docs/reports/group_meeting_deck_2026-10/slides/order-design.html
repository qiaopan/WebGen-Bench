这一部分回答一个一定会被问到的问题：v7 赢了 No Memory 11.5 个点，是不是因为同领域的题挨着做，前一题刚做过类似网站，后一题自然好做？为了回答它，我们把顺序分成两类。左边是领域挨着：除了已有的原顺序，再用种子 11 把领域块的先后和块内顺序打乱，同领域仍连续做。右边是领域打散：种子 29，101 题完全随机，相邻题大多来自不同领域。考虑到时间成本，两类各新跑一次。每种顺序下两组逐题背靠背，ABBA 轮换谁先跑。No Memory 一共跑 3 次，用来量出运行本身的波动，作为判断 11.5 个点是否可信的参照。原论文的结果都是单次运行、没有误差线，作者在自查清单里说明是因为计算成本，这里我们做得更严谨一些；不过打散这一类只有一次运行，结论只能算初步。解读方式：两类都赢，说明记忆普遍有效；只有挨着赢，说明收益来自同领域经验。
