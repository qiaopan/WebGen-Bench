顺序鲁棒性 · 实验设计

对 Long Memory 来说，任务顺序就是实验变量

四种顺序，每次从空库开始

  1. 原始 manifest（领域分块）
  2. 分层打乱，种子 11
  3. 分层打乱，种子 29
  4. 跨领域轮换交错

两臂交叉执行（ABBA）

每题 Long Memory 和 No Memory 背靠背；谁先跑逐题轮换：L→N，N→L，L→N……

抵消集群负载、评测状态随时间的漂移。

报告：按任务配对的差值 + bootstrap 置信区间；按领域、位置分组。

顺序鲁棒性。原来的 benchmark 每题独立，顺序无所谓；但对 Long Memory 来说，顺序决定了每道题能看到哪些经验，所以顺序本身就是实验变量。我们计划跑四种顺序，每次都从空库开始：原始的领域分块顺序、两个不同种子的分层打乱，以及跨领域轮换交错。每种顺序下，两组逐题背靠背执行，谁先跑按 ABBA 轮换，抵消集群负载随时间的漂移。四种顺序都提升，说明记忆普遍有效；只有领域分块有效，说明是邻近领域效应；交错明显变差，说明跨领域检索是瓶颈。
