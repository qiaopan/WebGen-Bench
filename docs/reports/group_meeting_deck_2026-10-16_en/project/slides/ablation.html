Ablation study · checklist vs. memory

Memory, not the checklist, drives the gain

Same generator, tester and task order; only one component changes per step. Paired bootstrap 95% CI over 101 tasks.

This is the ablation. The checklist alone adds 3.4 points, which is not significant, but zero-score tasks drop from 30 to 18. Adding memory adds 8.1 more points, which is significant. So memory, not the checklist, drives the gain.
