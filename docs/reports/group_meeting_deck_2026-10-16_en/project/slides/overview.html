This is the big picture. The top row is the official baseline: the request goes to the Bolt.diy agent with WebGen-LM-7B. Then the WebVoyager agent with Qwen 32B clicks and checks the features, and the same model grades a screenshot for appearance. Long Memory adds the blue loop. After each task, Qwen 72B saves short fixes in a memory bank. Before the next task, it adds a checklist and code examples. Everything else stays the same.
