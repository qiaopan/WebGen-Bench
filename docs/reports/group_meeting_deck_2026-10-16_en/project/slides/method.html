Method (v7)

Two parts: a checklist and a code pool

1. Requirement checklist

The memory model splits the request into a list. Each lesson sits under the item it belongs to. The request always comes first.

2. Code pool

When a code error appears in 2 tasks, take a short fix from our own earlier site that worked. At most 15 lines, checked by a compiler.

Example: import { ref } from 'vue' · const bookingId = ref('')

So our method, v7, has two parts. First, a requirement checklist: the request is split into a list, and each lesson sits under its item. Second, a code pool: when a code error appears in two tasks, we take a short fix from our own earlier site. It is at most 15 lines, and checked by a compiler.
