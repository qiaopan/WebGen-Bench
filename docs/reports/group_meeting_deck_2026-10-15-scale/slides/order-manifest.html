问题：修复后的 v9.1 是否保住 v7 的优势？

v7（已完成）

40.0% vs No Memory 28.5%
配对 +11.5（6.0～16.9），零分 30 → 13
脚手架 2 题

v9.1（运行中）

只跑 Long Memory，与同一个 No Memory 比较
预计 10-16 早上完成

原顺序的两组不是逐题交替执行（时间上不配对），其余顺序都是

第一个顺序是基准自带的原顺序，同领域的题按块排在一起。v7 在这里得到主结果：40.0% 对 28.5%，配对高 11.5 个点，显著，零分题从 30 降到 13，只出现 2 个脚手架。这里要回答的是：修复后的 v9.1 能不能保住这个优势。v9.1 只跑 Long Memory，和同一个 No Memory 比较，预计周五早上完成。要注意原顺序的两组是在不同时间跑的，不像其他顺序那样逐题交替。
