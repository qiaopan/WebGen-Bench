实验总表 ① · 各组别是什么

六个组别：一个基线、一个消融、四个记忆版本

组别内容用途
No Memory只给需求原文，不读写记忆基线（复现论文 28.4%）
v4需求清单 + 文字经验早期版本：文字记忆
只有清单v7 配置，但不读写任何记忆消融：需求拆解的贡献
v7清单 + 文字经验 + 代码池（整份文件示例）原顺序主结果
v8 / v9v7 的代码池修复的中间版本开发中，已停止
v9.1代码池只给核对过的关键行；整站崩溃 1 次即建记忆；编译错误对所有 Vue 网站适用最终版本：顺序实验

所有组别：WebGen-LM-7B + Bolt，官方协议（只生成一次、不修复），101 题，Qwen2.5-VL-32B 评测。

先用两页把所有实验放在一起。第一页是组别。No Memory 是基线，只给需求原文，复现出 28.5%，和论文的 28.4% 几乎一样。v4 是早期的文字记忆版本。只有清单是消融：和 v7 配置完全相同，但不读写任何记忆，用来分出需求拆解的贡献。v7 是原顺序的主结果，加入了代码池，但代码池里有一条示例是整份别的网站的文件。v8 和 v9 是修这个问题的中间版本，各自发现了新问题后停止。v9.1 是最终版本：代码池只给经过代码核对的关键几行，整站崩溃的问题出现一次就建记忆，编译错误类的记忆对所有 Vue 网站都适用。所有组别都用同一个生成器、同一个评测，官方协议，101 题。
