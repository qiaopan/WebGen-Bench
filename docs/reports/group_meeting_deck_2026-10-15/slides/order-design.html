种子 47同上，换一个种子种子 11 的结果是否偶然约 10-17
种子 29101 题完全随机领域打散，是不是靠同领域挨着已完成

每个顺序都从空记忆开始，Long Memory 与 No Memory 逐题背靠背、ABBA 轮换谁先跑，按题配对报告差值和置信区间。

为什么要做顺序实验？原论文的基准是静态的，每题独立做，顺序无所谓。但有了记忆，任务顺序决定了做到第几题时能用上哪些经验；原顺序里同领域的题挨着，后一题总能借到刚做过的类似网站，所以审稿人一定会问：提升是不是因为同领域的题挨着做？我们设计了五种顺序，分两类。领域挨着：原顺序、种子 11 和种子 47，后两个把领域块的先后和块内顺序打乱。领域打散：种子 29 完全随机，交错顺序让相邻题都来自不同领域，是对记忆最不利的情况。每种顺序都从空记忆开始，和 No Memory 逐题背靠背交替跑，谁先跑轮换，避免时间漂移影响某一组。下面每一页讲一个顺序验证什么、结果怎样。
