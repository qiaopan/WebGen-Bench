问题：换一个领域先后，记忆还有效吗？——修复后显著有效

No Memory 27.9% · v7 33.1%（+4.4，不显著，脚手架 19） · v9.1 35.4%（+7.4，CI 1.6～13.1，脚手架 0），零分 29 / 21 / 16

第二个顺序是种子 11：把领域块的先后和块内题目都打乱，同领域仍然挨着。它回答：换一个领域的先后，记忆还有没有用。v7 在这里只比 No Memory 高 4.4 个点，不显著。原因是从第 36 题开始，代码池里“缺包”那条记忆注入了一整份别的网站的 App.vue，之后模型交了 19 个原封不动的 Vite 脚手架，No Memory 一个都没有。修复后的 v9.1 脚手架降到 0，比 No Memory 高 7.4 个点，置信区间 1.6 到 13.1，显著，零分题从 29 降到 16。图上是 v9.1 减去 No Memory 的 10 题滑动差值，第 50 到 58 题还有一段低谷，但只到 −9 左右，v7 在同一段掉到了 −32。
