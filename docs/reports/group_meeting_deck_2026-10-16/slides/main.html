主结果。三组都在 101 题、同一顺序上各跑一次。全部 101 题，v7 是 40.0%，v4 是 30.9%，No Memory 是 28.5%；零分题从 30 降到 13。逐题配对的话，v7 比 No Memory 平均高 11.5 个百分点，95% 置信区间是 6.0 到 16.9，54 题赢、24 题输。分段看，前 30 题 v4 和 v7 差不多；后面 v4 掉到 No Memory 以下，v7 在第 61 到 101 题仍然有 37.1%，比 No Memory 高 12 个点。还要注意，第 61 到 101 题三组都比中段低，说明后段题目更难。
