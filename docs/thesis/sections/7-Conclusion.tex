\section{Future Work}
A stronger generator from the same family (WebGen-LM-32B) would test whether the advantage of code over text depends on model capability. One further experiment would address the main remaining question:
\begin{itemize}
  \item \textbf{Held-out evaluation.} Because the method was developed while observing results on this benchmark, freeze the method on the first 30 tasks and report the remaining 71 separately.
\end{itemize}
Further directions are re-grading with a second strong \gls{vlm} evaluator, integrating the memory with other coding agents (e.g.\ OpenHands, Aider) on a stratified subset of tasks, letting the memory model revise reflections and fragments until code-checkable criteria hold~\cite{madaan2023selfrefine,dhuliawala2023cove}, and transferring the approach to repository-level coding benchmarks such as SWE-bench.
