\section{Future Work}
\begin{itemize}
  \item \textbf{Other generators.} Repeat the main comparison with one generator of a different architecture or capability, keeping Bolt.diy fixed, to test whether the code-over-text effect is specific to small models.
  \item \textbf{Other agents.} Integrate the memory with other coding agents (e.g.\ OpenHands, Aider) on a stratified subset of tasks once the effect is stable.
  \item \textbf{Other evaluators.} Re-grade existing screenshots with a second strong \gls{vlm} and re-check a stratified sample of functional verdicts.
  \item \textbf{Ablations.} Fixed code prefix from task one; without the concreteness filter; different trigger thresholds.
  \item \textbf{Verification loops for memory.} Let the memory model revise reflections and fragments until code-checkable criteria hold~\cite{madaan2023selfrefine,dhuliawala2023cove}.
\end{itemize}
