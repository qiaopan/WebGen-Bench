IMPLEMENTATION GUIDANCE FOR THIS WEBSITE

Implement the following concrete behaviours in the generated website. Treat these as
required implementation instructions for the current website, not merely background
examples.

1) Navigation
Render exactly these navigation labels: Home, About Us, Services, and Contact Us.
Bind each label to its corresponding page/route. Verify every navigation entry by
clicking it and confirming the expected page content is visible.

2) Contact form confirmation
Implement an explicit submitted/success state in the contact form. Validate the
fields first; after valid submission set submitted=true and render a persistent inline
confirmation element on the page. Do not rely only on window.alert. Do not clear the
fields before setting the success state. Clear fields only after the success branch is
rendered. Verify by entering valid name/email/message values, clicking Send once, and
checking that the confirmation remains visible after the click.
